# MVP ручной проверки

Пользователь согласовал приемлемый вариант без обязательных90%. Выбрана profile-XGBoost, почти равная CatBoost по PR-AUC и уже поддерживаемая сервисом. Модель не переобучалась: проверенные веса упакованы с политикой review_queue. Порог0.407402902841568 выбран на validation для precision≥60%, минимум100 отмеченных аккаунтов.

Validation: precision60.40%, recall19.86%, 2520/29917 аккаунтов (8.42%) в приоритетной очереди. Это 1522 бота и998 ложных срабатываний. Порог исследовательский, независимая проверка на Threads отсутствует. Низкая оценка не подтверждает человека, score не является откалиброванной вероятностью.

Сервис возвращает priority_review / standard_review / insufficient_data. Требуются followers, following, biography (пустая строка допустима), has_avatar (false допустимо). Отсутствующее поле не заменять нулём. Посты для профильной модели не нужны. CRM сортирует оценки по убыванию, пропуски в конце; ручные метки сохраняются отдельно. Объяснения показывают вклады признаков в оценку, не причины автоматизации.

Сборка: `.venv/bin/python -m scripts.build_review_model`; исходный артефакт и val проверяются по SHA256, выходная папка не перезаписывается. Локальная модель media/models/review-mvp-v1/model.joblib; активная копия media/models/portable.joblib. Для возврата к состоянию без модели убрать активную копию и перезапустить api/worker. Исследовательские модели сохранены.

Дальше: реальный импорт Threads с профильными полями, ручная разметка и проверка precision/recall на независимом наборе. Если импорт содержит только тексты, результат будет недостаточно данных. Проверка smoke использует синтетический профиль исключительно для интеграции, не для оценки качества.

## Использование

Открыть http://127.0.0.1:8100/engine/, войти, импортировать JSON и запустить анализ. Для профиля без публикаций используйте `data/examples/profile-review.json`: замените демонстрационные сведения реальными, сохраняя `posts: []`. Это демонстрация формата, не реальный аккаунт. CSV/JSONL остаются форматом строк публикаций и требуют post_id/created_at; не выдумывайте посты ради импорта профиля. Наличие аватара принимается как true/false; пустое значение означает неизвестно.
