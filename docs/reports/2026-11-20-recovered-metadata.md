# Восстановление метаданных URL и адресатов

Дизайн: docs/superpowers/plans/2026-11-20-recovered-metadata.md. Восстанавливаются expanded_url и ID адресатов для тех же8312220 выбранных постов183205 train/val аккаунтов. Проверяется SHA256 всего raw. Test не оценивается; полный raw проход физически читает общий файл, включая записи вне train/val, но не использует их для признаков/обучения/оценки. Старые prepared данные и активная модель не меняются.

Новые признаки: доли известных entities URLs/targets, доля постов со ссылками/адресатами среди известных, число уникальных доменов/адресатов, концентрация доменов/адресатов и повторяемость точных раскрытых URL. Дополнительно маски отсутствия. Это свойства наблюдаемого bottom100 набора, а не полной истории аккаунта. Временные признаки не включаются. Entities-only данные не объединяются с текстовыми ссылками, чтобы не скрыть несовпадение покрытия.

Два заранее заданных варианта: профиль+metadata и профиль+прежняя структура+metadata. XGBoost300деревьев/depth4/lr.05/seed42, без подбора параметров и class weights. Импутация только train. Сравнение по2520 аккаунтов в validation очереди; ID применяется лишь для детерминированного разрешения одинаковых score, не как признак. Результат исследовательский, не подтверждает качество Threads.

Запуск: `.venv/bin/python -m scripts.recover_metadata_experiment`. Каталог media/models/experiments/recovered-metadata-v5 создаётся один раз. После успешного сохранения metadata.npy+extraction.json можно повторить запуск для обучения; выполненная оценка не перезаписывается. Прерванное извлечение до сохранения требует отдельного нового каталога/явного удаления только незавершённой папки оператором. Автоматического resume raw scan нет.

Ограничения: expanded_url может оставаться сокращателем; точные URL учитывают query и не объединяют tracking-варианты. Targets отражают лишь явные упоминания/ответы. Наличие ключей entities не доказывает полноту метаданных. Исходный сторонний фрагмент не является полным TwiBot-22.

## Фактический результат

Полный проход10000000записей, обработка226с без времени построения выбранныхID. Найдены все8312220выбранных постов. SHA256raw совпал. Некорректная metadata у1поста отмечена unknown; у1890089постов количество текстовыхURL и entityURL различается.

| Активный профиль |1522|998|60.40%|19.86%|

Новая информация восстановлена, но эти агрегаты не улучшили модель. Активный MVP оставлен без изменений. Из этого не следует, что ссылки/адресаты бесполезны: проверены только индивидуальные агрегаты, не повторные межаккаунтные связи. Следующий эксперимент имеет смысл строить на повторных общих ссылках/адресатах и временных совпадениях с контролем полноты, либо на новой размеченной выборке Threads. Подбор по многократно использованной validation не заменяет независимого контроля.

Артефакты повторно загружены, рейтинги совпали. Первый scan исполнялся до добавления guard повторного использования кэша; формулы не менялись. Identity плана сохранена во время прохода и сверена после него. [Полные результаты, coverage, хеши и версии](2026-11-20-recovered-metadata.json).
