# Сравнение признаков и моделей — 20 ноября 2026

Шесть заранее фиксированных запусков на одинаковых 153288 train и 29917 validation аккаунтах. Test не читался. Порог лучшего F1 и цель precision≥90% при минимум100 положительных прогнозах определяются по validation. Это исследовательский результат, не оценка качества на Threads.

|---|---:|---:|---:|---:|---:|

| profile-catboost | 0.4523 | 0.6930 | 0.4801 | 0.3659 | 0.6978 |

| posts-catboost | 0.3124 | 0.5707 | 0.4108 | 0.2619 | 0.9526 |

Ни один запуск не достиг precision90% при минимум100 отмеченных аккаунтах. Лучшая PR-AUC у profile-catboost: 0.45232 (profile-xgboost: 0.45215). У combined-catboost 0.44294, у combined-xgboost 0.43788. Добавление структуры публикаций к профилю снизило PR-AUC, хотя немного увеличило лучший F1. Добавление профиля даёт большее улучшение, чем смена алгоритма. Разница алгоритмов мала и не подтверждена независимым контролем.

Профиль: followers_log1p, following_log1p, их отношение, bio_present, avatar_present. Публикации: девять прежних структурных признаков. Для каждого есть маска пропуска. Возраст исключён из-за неизвестной даты исторического снимка. Покрытие признаков в JSON. Медианы вычислены только на train. Все модели300деревьев, depth4, lr0.05, seed42; веса классов и early stopping отключены. Разные внутренние defaults алгоритмов сохранены: это фиксированный baseline, не исчерпывающий поиск лучшей модели.

Артефакты: media/models/experiments/feature-model-comparison-v3/. Каждый сохранённый pipeline повторно загружен; прогнозы совпали.
