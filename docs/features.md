# Каталог признаков portable-v1

Одна реализация engine.features.extract_features используется при подготовке и распознавании.
Набор содержит 31 числовой признак и 31 маску `<name>__missing` (1 — неизвестен, 0 — известен).
В JSON пропуск — null, в матрице ML — NaN. Импутация обучается только на train.
Ни label, ни external_id, ни split, ни язык в матрицу не входят.

`n` — число наблюдаемых постов; `Δ` — интервалы в секундах; `μ/σ` — среднее и
population standard deviation. Неизвестные булевы значения исключаются из знаменателя.
Любой временной признак требует `complete=true`, `truncated=false` и положительного
окна; CSV/JSONL и keyword search всегда имеют неполное покрытие. Это консервативное
правило не позволяет модели выучить интенсивность выборки как активность аккаунта.
Все календарные вычисления — UTC. Отсутствие локальной «ночной активности» намеренно.

| Признак | Формула / единица | Минимум данных |
|---|---|---|
| followers_log1p | ln(1 + followers) | известное число followers |
| following_log1p | ln(1 + following) | известное число following |
| followers_following_ratio | followers / (following + 1) | оба числа |
| bio_present | непустая biography, 0/1 | поле biography известно |
| avatar_present | наличие аватара, 0/1 | поле has_avatar известно |
| account_age_days | (collected_at − created_at)/86400 | известна дата исторического снимка; возраст неотрицательный |
| posts_per_day | n / длительность окна в сутках | n≥1, полное окно |
| interval_median_s | медиана Δ | n≥2, полное окно |
| interval_p90_s | nearest-rank 90-й процентиль Δ | n≥2, полное окно |
| interval_cv | σ(Δ)/μ(Δ) | n≥2, μ>0, полное окно |
| burstiness | (σ−μ)/(σ+μ) | n≥2, σ+μ>0, полное окно |
| short_interval_ratio | доля Δ<60 секунд | n≥2, полное окно |
| hour_entropy | −Σ p(hour)·log2 p(hour) / log2 24 | n≥1, полное окно |
| circadian_amplitude | модуль среднего exp(2πi·UTC_hour/24) | n≥1, полное окно |
| max_posts_per_hour | максимум счётчика UTC-часовых бакетов | n≥1, полное окно |
| active_day_ratio | число активных UTC-дней / число календарных дней закрытого окна | n≥1, полное окно |
| reply_ratio | среднее известного is_reply | ≥1 известный флаг |
| repost_ratio | среднее известного is_repost | ≥1 известный флаг |
| quote_ratio | среднее известного is_quote | ≥1 известный флаг |
| media_ratio | среднее известного has_media | ≥1 известный флаг |
| duplicate_ratio | 1 − уникальные/все непустые нормализованные тексты | ≥1 непустой текст |
| text_length_median | медиана длин после Unicode NFKC, code points | ≥1 известный текст |
| text_length_cv | σ/μ длины | ≥2 известных текста, μ>0 |
| text_digit_ratio | число Unicode-цифр / число символов | ≥1 символ |
| text_space_ratio | число Unicode-пробельных символов / число символов | ≥1 символ |
| text_punctuation_ratio | число символов Unicode category P / число символов | ≥1 символ |
| url_ratio | доля постов с URL среди постов с известным текстом/urls | ≥1 известный текст/список URLs |
| unique_domains | число уникальных валидных hostname | ≥1 известный текст/список URLs |
| domain_concentration | Σ(частота hostname / число URL)² | ≥1 валидный URL |
| unique_targets | число уникальных targets | ≥1 известный список targets |
| target_concentration | Σ(частота адресата / все адресаты)² | ≥1 адресат |

Дубликаты: NFKC → casefold → схлопывание пробелов; пустые тексты исключаются.
Это не семантическая близость. Длины и структура текста могут отличаться между
письменностями; эти признаки не требуют языковой модели, но их переносимость
необходимо подтвердить ablation и выборкой Threads.

Все признаки условно доступны и в Twitter, и в Threads через единый контракт.
Их реальная доступность зависит от полей источника. Открытая часть TwiBot-22
содержит профили; collected_at неизвестен, поэтому возраст не выдумывается.
Keyword search Threads может не вернуть follower/following и стабильный author ID.
Такой автор помечается identity_source=username_fallback, external_id=username:…;
его нельзя автоматически приравнивать к аккаунту с платформенным ID.

Контекстный граф рассчитывается отдельно в engine.coordination: совпадения
UTC-бакетов, общие URL и адресаты. Требуются повторные совпадения или общие
объекты. Крупные бакеты исключаются, число кандидатов ограничено; усечение
возвращается в ответе. Оценка координации не смешивается с вероятностью бота.
