# ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ

| Сокращение | Расшифровка |
|---|---|
| API | Application Programming Interface — программный интерфейс приложения |
| CIB | Coordinated Inauthentic Behavior — скоординированное неаутентичное поведение |
| CRM | система учёта и разметки аккаунтов аналитиком |
| FN | False Negative — пропущенный бот |
| FP | False Positive — человек, ошибочно отмеченный как бот |
| GNN | Graph Neural Network — графовая нейронная сеть |
| ML | Machine Learning — машинное обучение |
| PR-AUC | площадь под кривой «точность — полнота» |
| ROC-AUC | площадь под ROC-кривой |
| SHAP | SHapley Additive exPlanations — метод объяснения вклада признаков |
| TP | True Positive — правильно найденный бот |
