# TwiBot-20/22: подготовка baseline

TwiBot-22 используется как источник реальной разметки для первого языконезависимого baseline.
Большие файлы датасета и сведения о конкретных пользователях нельзя коммитить в этот репозиторий.

## Официальная структура TwiBot-22

- `user.json` — массив профилей пользователей;
- `label.csv` — `id,label`, где label равен `human` или `bot`;
- `split.csv` — `id,split`, где split равен `train`, `valid` или `test`;
- `tweet_0.json` … `tweet_8.json` — публикации, пока не используются profile baseline;
- `edge.csv` — связи, будут подключены на сетевом этапе.

Доступ к полному датасету выдаёт команда TwiBot-22 по академическому запросу. Используйте данные
только для исследования и не публикуйте сведения об отдельных аккаунтах.

## Языконезависимые признаки

Первый baseline не читает тексты, имя или описание как естественный язык. Он использует только
числовые метаданные и длины полей: число подписчиков и подписок, число публикаций и списков,
их соотношение, возраст профиля, длины username/name/description и флаги заполненности,
верификации, приватности и наличия изображения.

Возраст считается относительно фиксированной даты `2022-01-01`, чтобы один и тот же датасет
давал одинаковые признаки при повторном запуске.

## Запуск

```bash
python manage.py train_twibot22_baseline \
  --dataset /path/to/TwiBot-22 \
  --output media/models/twibot22-baseline
```

Команда использует официальный `split.csv`, обучается только на `train` и отдельно считает
метрики на `valid` и `test`. Результат:

- `model.joblib` — модель, imputer и порядок признаков;
- `metrics.json` — Precision, Recall, F1, PR-AUC, Accuracy, Balanced Accuracy и confusion matrix.

Для проверки установки на небольшой части:

```bash
python manage.py train_twibot22_baseline \
  --dataset /path/to/TwiBot-22 \
  --max-per-split 5000
```

Метрики такого ограниченного запуска получают предупреждение и не подходят для диплома.

## Методологические ограничения

- Метрики на TwiBot-22 нельзя выдавать за качество на Threads.
- `test` нельзя использовать для подбора параметров или порога.
- Profile baseline сравнивается с будущей моделью с поведенческими и сетевыми признаками.
- Полный эксперимент следует повторить с несколькими seed и зафиксированными версиями зависимостей.
